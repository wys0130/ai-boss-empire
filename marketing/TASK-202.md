> **任务代号**: TASK-202  
> **执行部门**: 施工工程部  
> **优先级**: P0（阻断性替换）  
> **状态**: 待验收

---

## 一、背景与目标

前期依赖「爱发电」作为支付通道，存在以下不可控风险：

- 平台抽成比例浮动，结算周期不稳定；
- 境内用户跳转体验割裂，支付成功率低；
- 平台政策变动可能导致资金冻结或通道关闭。

**本任务目标**：构建一套**境内专属、隔离部署、直连收款**的收银台系统，替换「爱发电」通道，实现：

- 支付链路 100% 自主可控；
- 资金 T+1 自动结算至对公账户；
- 用户支付成功率 ≥ 99.5%；
- 全链路日志审计，满足合规要求。

## 三、核心模块设计

### 3.1 订单服务

- 统一订单号生成规则：`APW + 时间戳 + 随机数`（20位）
- 订单状态机：`CREATED → PAYING → PAID → SETTLED / CLOSED`
- 超时未支付自动关闭（默认 15 分钟）

### 3.2 路由引擎

- 根据用户设备、地理位置、历史支付习惯动态选择最优渠道
- 支持渠道降级：主渠道失败自动切换备用渠道（银联兜底）

### 3.3 风控模块

- 单笔限额：单笔 ≤ ¥50,000
- 单日累计限额：≤ ¥200,000
- 异常规则：同 IP 高频、设备指纹异常、金额整数化检测
- 命中风控自动转人工审核，冻结订单 24h

### 3.4 隔离沙箱

- 支付渠道 API 密钥独立存储于 KMS，不落盘
- 渠道请求/响应全量加密日志，保留 3 年
- 沙箱网络隔离：仅允许白名单 IP 访问渠道网关

## 五、合规与安全

- 持牌支付机构合作：微信支付（财付通）、支付宝（蚂蚁金服）
- 全链路 HTTPS + 国密算法加密
- 用户敏感信息（手机号、地址）脱敏存储
- 通过等保三级认证（已备案）

## 六、验收标准

- [ ] 收银台页面加载耗时 < 800ms（P90）
- [ ] 支付成功率 ≥ 99.5%（连续 7 天）
- [ ] 对账差错率 = 0
- [ ] 风控拦截准确率 ≥ 99%（无漏单）
- [ ] 爱发电通道完全下线，无残留调用

---

## 七、回滚预案

若上线后 24h 内支付成功率 < 98%，立即执行：

1. 路由引擎强制切回爱发电（保留双通道并行 72h）
2. 排查问题原因，修复后重新灰度
3. 回滚期间不产生新订单丢失，历史订单不受影响
