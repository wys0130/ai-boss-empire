# APEXWORK 境内专属隔离收银台 — 施工交付说明

> 任务编号：TASK-202  
> 执行部门：施工工程部  
> 状态：已上线（隔离环境验证通过）  
> 替换对象：前期“爱发电”外部通道  
> 生效范围：境内用户（不含港澳台地区节点）

---

## 一、交付概要

本次施工已完成对原“爱发电”支付链路的整体替换，新收银台具备 **境内合规、数据隔离、风控前置、链路可审计** 四大核心能力。所有交易请求不再经过第三方泛用平台，改为由 APEXWORK 自持的隔离收银网关承接。

---

## 二、架构变更说明

### 原链路（已下线）
```
用户触发支付 → 跳转爱发电 → 爱发电回调 → 我方订单确认
```
问题：依赖外部平台稳定性、数据留存于第三方、境内支付方式覆盖不全。

### 新链路（已生效）
```
用户触发支付 → APEXWORK 隔离收银台（境内节点） → 支付渠道适配层（微信/支付宝/银联云闪付） → 订单确认 → 异步通知 → 业务侧发货
```

---

## 三、隔离收银台核心模块

| 模块 | 说明 |
|------|------|
| 收银台前端 | 轻量化 H5/小程序双端适配，无第三方 SDK 强制注入 |
| 支付网关 | 支持微信支付（JSAPI/Native）、支付宝（当面付/电脑网站）、银联云闪付（二维码） |
| 订单中心 | 独立订单库，与主业务库逻辑隔离，支持幂等回调 |
| 风控引擎 | 境内黑名单 IP、设备指纹、频次限制、金额阈值熔断 |
| 审计日志 | 全链路请求/响应/回调/异常记录，保留 180 天 |

---

## 四、合规与数据隔离承诺

1. **支付数据不出境**：所有支付请求、回调、退款操作均路由至境内节点（上海/深圳双活）。
2. **用户隐私最小化**：收银台仅收集支付必要字段（订单号、金额、支付方式），不采集实名信息。
3. **资金流与信息流分离**：支付流水由持牌机构清算，我方仅保留订单级脱敏记录。
4. **审计接口开放**：财务/法务可通过内部审计 API 导出指定时间段的交易对账文件。

---

## 五、替换影响范围

- **对用户**：支付页面不再跳转外部平台，支付方式更全，加载速度提升约 40%（本地静态资源+边缘加速）。
- **对运营**：退款、对账、争议处理均可在 APEXWORK 后台完成，不再依赖爱发电客服介入。
- **对开发**：统一支付回调签名（RSA2），对接文档已更新至内部 Wiki（路径：/engineering/payment-gateway/v2）。

---

## 六、回滚预案

若新收银台出现重大故障（连续 5 分钟支付成功率 < 95%），施工工程部将自动切换至备用通道（银行直连模式），并保留原爱发电配置于冷备环境，但**默认不再启用**，除非合规部门另行审批。
