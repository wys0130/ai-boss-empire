## 二、广州网络经营个体户执照（核心参数）

### 1. 适用主体
- 以个人名义在抖音/淘宝/微信小店/小红书等平台开展电商、直播、知识付费、软件服务。
- 无实体办公场地要求（需挂靠广州正规集群注册地址）。

### 2. 办理条件（硬性门槛）
| 项目 | 要求 |
|------|------|
| 申请人 | 中国大陆年满18周岁自然人 |
| 经营范围 | 需包含“互联网销售（除销售需要许可的商品）”或“信息技术咨询服务” |
| 注册地址 | 广州任一区集群注册地址（天河/白云/番禺均可） |
| 注册资本 | 认缴制，1元起（建议填1-10万，不实缴） |
| 银行账户 | 可后补，但需在税务报道前完成 |

### 3. 办理时效与费用
- 全程电子化办理：3-5个工作日下证（市场监管局系统“一网通办”）。
- 费用：政府工本费0元；代办+挂靠地址市场价 800-1500元/年（含税务报道）。

### 4. 关键税务参数（2025年现行）
| 税种 | 税率/规则 |
|------|-----------|
| 增值税 | 小规模纳税人：月销售额≤10万免征（普票）；超过部分按1%征收（至2025年底） |
| 个人所得税（经营所得） | 查账征收：5%-35%五级累进；核定征收：广州目前对电商个体户普遍按 0.8%-1.2% 应税所得率核定（需申请） |
| 附加税 | 增值税的7%（城建税）+3%（教育附加）+2%（地方教育），月销售额≤10万时随增值税免征 |
| 年报 | 每年1月1日-6月30日，通过“国家企业信用信息公示系统”填报 |

### 5. 平台入驻要求（对公或个体户均可）
- 抖音小店：个体户执照 + 法人身份证 + 银行账户（可对私，但建议对公）
- 微信小店：必须提供对公账户（或个体户法人银行卡，但提现限额）
- 淘宝/天猫：个体户仅支持“淘宝店”，天猫必须企业执照

## 三、对公账户参数（广州地区）

### 1. 开户银行选择（推荐）
| 银行 | 开户费 | 管理费 | 网银转账限额 | 备注 |
|------|--------|--------|--------------|------|
| 招商银行广州分行 | 0 | 0（月均≥5万免） | 单笔500万 | 支持个体户开户，需上门核实 |
| 工商银行广州支行 | 0 | 100元/月（可谈减免） | 单笔200万 | 网点多，适合传统结算 |
| 网商银行（支付宝） | 0 | 0 | 单笔100万 | 纯线上，但需已有支付宝经营记录 |
| 微众银行（微信） | 0 | 0 | 单笔50万 | 适合微信生态，需法人人脸识别 |

### 2. 开户必备材料（个体户专用）
- 营业执照正副本原件
- 经营者身份证原件
- 经营场所证明（集群地址需提供挂靠协议）
- 经营业务证明（如平台店铺后台截图、采购合同等）
- 预留印鉴章（公章、财务章、经营者私章）

### 3. 开户流程与时效
1. 预约银行客户经理（提前3-5个工作日）
2. 银行上门核实经营地址（集群地址需配合拍照）
3. 柜台面签 + 设置网银U盾
4. 下户时间：3-7个工作日（含人民银行备案）

### 4. 对公账户风控红线（必读）
- 严禁代收代付、流水快进快出（单日进出超50万触发预警）
- 每月至少保持1笔真实经营流水（金额不限）
- 地址变更需在30日内向银行报备
- 长期（6个月）无交易会被冻结，解冻需提供业务合同

## 四、执行SOP（董事长签发）

```
第1周：选定代办机构（需查验其“集群注册”资质）
第2周：提交执照申请 → 3-5天下证 → 同步预约银行
第3周：银行开户（上门核实+面签） → 领取U盾
第4周：税务报道（电子税务局） → 申请核定征收 → 完成社保/公积金登记（如需）
第5周：平台店铺资质更新（个体户执照+对公账户绑定）
```
