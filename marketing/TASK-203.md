## 一、智能判断逻辑（多模态设计组）

### 1. 输入信号源
- 用户行为埋点（点击、停留、转化）
- 行业热点词库（每日抓取）
- 竞品模板库更新（视觉风格比对）
- 内部素材标签体系（色彩/版式/行业）

### 2. 判断模型（三层过滤）
```
第一层：需求热度评分（0-100）  
  - 搜索量 + 转化率 + 社交提及量  
第二层：视觉风格匹配度（0-100）  
  - 与当前品牌VI相似度 + 流行趋势拟合  
第三层：产能可行性（0-100）  
  - 现有素材库覆盖度 + 设计人力负载  
```
> 综合分 ≥ 75 → 进入今日生成队列  
> 综合分 60-74 → 进入明日候选池  
> 综合分 < 60 → 自动丢弃并记录原因

## 四、质量护栏（防呆机制）

1. **品牌违禁词库**：自动拦截敏感词/竞品词  
2. **视觉一致性校验**：色彩偏离 > 15% 自动打回  
3. **尺寸适配检查**：自动生成多尺寸（1:1, 16:9, 9:16）  
4. **版权风险扫描**：图片素材来源标记 + 商用许可校验  
5. **人工抽检**：每日随机抽 5% 模板人工复核
