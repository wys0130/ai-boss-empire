## 一、智能判断多模态设计组（MDA - Multimodal Design Assembly）

### 1.1 判断逻辑（三层过滤）

| 层级 | 判断维度 | 输入信号 | 输出决策 |
|------|----------|----------|----------|
| L1 | 内容模态匹配 | 文本 / 图片 / 视频 / 音频 / 3D模型 | 是否进入设计组 |
| L2 | 模板语义契合 | 行业标签、风格向量、品牌色板、排版密度 | 选择模板家族 |
| L3 | 转化意图预测 | 历史CTR、互动率、目标人群画像 | 生成优先级排序 |

### 1.2 设计组自动分工

```
输入流 → 模态识别器 → 语义解析器 → 模板匹配器 → 生成器（文案/视觉/动效） → 质检器 → 输出队列
```

- **模态识别器**：判定输入是纯文本、图文、视频脚本还是多模态混合
- **语义解析器**：提取核心卖点、情绪基调、行动号召（CTA）
- **模板匹配器**：调用模板库中 200+ 行业模板，按相似度打分
- **生成器**：自动填充文案、生成配图建议、排版布局、动效建议
- **质检器**：检查品牌合规、敏感词、字符溢出、图片分辨率

## 二、每日自动生成模版推文流水线

### 2.1 流水线架构（每日 06:00 自动触发）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  数据采集    │ →  │  智能判断    │ →  │  模板生成    │ →  │  发布推送    │
│ (行业热点/   │     │ (MDA三层过滤)│     │ (文案+视觉)  │     │ (多平台适配) │
│  用户行为)   │     │             │     │             │     │             │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

### 2.2 每日产出物清单

| 时间 | 产出 | 格式 | 用途 |
|------|------|------|------|
| 06:00 | 行业热点简报 | Markdown | 内部参考 |
| 06:30 | 3 套推文模板（含文案+配图建议） | PNG + TXT | 公众号/小红书 |
| 07:00 | 1 条短视频脚本（含分镜） | JSON | 抖音/视频号 |
| 07:30 | 1 组多模态推文（图文+音频摘要） | HTML | 官网/社群 |

### 2.3 自动化规则

- **触发条件**：每日 06:00 或 手动触发（`/run pipeline daily`）
- **失败重试**：单环节失败自动重试 3 次，间隔 5 分钟
- **质量阈值**：质检器评分 < 85 分则自动回炉重写
- **人工介入**：每日 10:00 汇总生成日志，供主动产品部审核
